# DISA STIG Red Hat Enterprise Linux 9 (V2R10)

**Coverage label: partial** (see [`scripts/coverage_labels.json`](../../../scripts/coverage_labels.json) and the
label table in [COVERAGE.md](../../../COVERAGE.md)).

## What is in the module

- 104 rules of the V2R10 STIG, each compared with DISA's full check text (CHANGELOG, "DISA STIG RHEL 9 V2R10:
  rules test what the check text tests", #320). The STIG has more rules than this; the module is a subset.
- Generated by `tools/stig_generators/gen_rhel9.py` from the reviewed rule table
  `tools/stig_generators/rhel9_rules.py`; edit the table and regenerate, not the `.rego` files.
- Pass, fail and evidence-missing tests per rule under `tests/`.

## Why "partial", not "validated"

The module ran against facts from a real RHEL 9.6 host on 2026-11-20. About 45 of the fact paths the rules read
(new paths and `input.attest.<key>` attestations listed in the generator table) are not collected yet, so those
rules report `evidence missing` on a real host instead of a pass or a fail. The result is fail-closed and
trustworthy as far as it goes, but it is not a full assessment until the collector supplies those paths. Results
from the 104 rules are not a statement about the rest of the STIG.
