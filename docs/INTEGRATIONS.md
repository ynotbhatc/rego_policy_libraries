# Use the library in CI in sixty seconds

Two shapes, because the policies come in two shapes:

- **Framework and benchmark modules** (CIS, STIG, NIST, MAS, DPDP…) expose one entrypoint,
  `data.<framework>.main.compliance_report`, and report `violations` (plural) inside it. Evaluate them with **OPA**
  against a facts document. Conftest only looks for `deny`, `violation` and `warn`, so it would report nothing
  for these; use `opa eval`.
- **Enforcement gates** (`enforcement/terraform`, `dockerfile`, `cicd`, `ansible`, `kubernetes`, `supply_chain`)
  expose `deny` / `violation` / `warn` and work with **Conftest** as-is.

The OPA example is run in this repository's CI on every merge (`.github/workflows/opa-test.yml`, step "Integration examples"); the Conftest example is exercised by `converters/packaging/iac_scanners/test/roundtrip.sh` wherever conftest is installed.

## 1. GitHub Actions — evaluate host facts against a benchmark (OPA, GHCR bundle)

```yaml
# .github/workflows/compliance.yml
name: Compliance as Code
on: [push, pull_request]

jobs:
  cis-rhel9:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install OPA and oras
        run: |
          curl -sL -o opa https://github.com/open-policy-agent/opa/releases/download/v1.10.0/opa_linux_amd64_static
          chmod +x opa && sudo mv opa /usr/local/bin/
          curl -sL https://github.com/oras-project/oras/releases/download/v1.2.2/oras_1.2.2_linux_amd64.tar.gz | tar -xz oras
          sudo mv oras /usr/local/bin/

      - name: Pull the policy bundle (pin a release tag; :latest tracks main)
        run: oras pull ghcr.io/ynotbhatc/rego_policy_libraries:v2.3.3   # writes bundle.tar.gz

      - name: Evaluate and fail the job on non-compliance
        run: |
          # facts.json: the host facts the module documents in its header (gathered by your Ansible role, script, or CMDB export)
          opa eval -b bundle.tar.gz -i facts.json 'data.cis_rhel9.main.compliance_report' -f json > report.json
          python3 - <<'PY'
          import json, sys
          r = json.load(open("report.json"))["result"][0]["expressions"][0]["value"]
          viol = sorted(r.get("violations", []))
          count = r.get("violation_count", r.get("failed_controls", len(viol)))
          print(f"compliant={r['compliant']} violations={count}")
          for v in viol[:50]:
              print(" -", v)
          sys.exit(0 if r["compliant"] else 1)
          PY
```

Swap `cis_rhel9` for any framework key: `mas_trm`, `dpdp`, `nist_sp_800_53`, `stig.rhel_9`, … (every `<framework>.main`
package; list them with `opa inspect -a bundle.tar.gz`). Every report is fail-closed: an empty `facts.json` is a long
list of violations, never a pass.

## 2. GitHub Actions — gate a Terraform plan with Conftest

```yaml
  terraform-gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Fetch the library's enforcement gates
        uses: actions/checkout@v4
        with:
          repository: ynotbhatc/rego_policy_libraries
          ref: v2.3.3
          path: rego_policy_libraries
      - uses: open-policy-agent/conftest-action@v1
        with:
          files: tfplan.json                          # terraform show -json tfplan > tfplan.json
          policy: rego_policy_libraries/enforcement/terraform
          namespace: enforcement.terraform.plan
```

The Conftest layout with a namespace index is also generated by `converters/packaging/iac_scanners/build.py`.

## 3. GitLab CI

```yaml
compliance:
  image: registry.access.redhat.com/ubi9/ubi-minimal
  script:
    - curl -sL -o /usr/local/bin/opa https://github.com/open-policy-agent/opa/releases/download/v1.10.0/opa_linux_amd64_static && chmod +x /usr/local/bin/opa
    - curl -sL https://github.com/oras-project/oras/releases/download/v1.2.2/oras_1.2.2_linux_amd64.tar.gz | tar -xz -C /usr/local/bin oras
    - oras pull ghcr.io/ynotbhatc/rego_policy_libraries:v2.3.3
    - opa eval -b bundle.tar.gz -i facts.json 'data.cis_rhel9.main.compliance_report.compliant' -f raw | grep -qx true
```

## 4. Without a registry

```
git clone --depth 1 --branch v2.3.3 https://github.com/ynotbhatc/rego_policy_libraries
opa eval -d rego_policy_libraries/benchmarks/cis/rhel_9 -i facts.json 'data.cis_rhel9.main.compliance_report'
```

Or load the WASM bundle from the release assets into any language SDK: `converters/packaging/wasm/README.md`.
