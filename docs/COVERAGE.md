# Test coverage

This page moved. The coverage report is generated at the repository root and checked by CI
(`python3 scripts/coverage_report.py --check`, part of `make check-coverage`):

- [COVERAGE.md](../COVERAGE.md): which policy files have tests, the coverage label of every framework key
  (validated, partial, experimental) and the queue of untested files.
- [COVERAGE_SCAN.md](COVERAGE_SCAN.md): what the parser finds in every module, against the total each module declares.

This file carries no figures of its own, so it cannot disagree with those two.
