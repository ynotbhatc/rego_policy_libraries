The source for every row is [`STANDARDS_UPDATE_REGISTRY.md`](../../STANDARDS_UPDATE_REGISTRY.md); the library's side is the [CHANGELOG](../../CHANGELOG.md).

- [2026-11](2026-11.md): October to November 2026. DPDP Rule 4, EU AI Act Art. 5 and the SWIFT attestation lead; SWIFT, HITRUST, TISAX and COBIT behind upstream; the October 2026 DISA library, CIS Windows 10/11, Apache 2.4 and MCP shipped in release 2.5.0.
