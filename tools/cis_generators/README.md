# CIS module generators

Generators that build a CIS benchmark module from the benchmark's own text. The
PDFs are CIS-licensed and are not committed; each script reads a `pdftotext -layout`
extraction supplied on the command line, verifies the recommendation ids and
titles it finds against its hand-authored logic table (a recommendation without
logic, or logic without a recommendation, aborts), and emits the module and its
tests.

- `gen_oracle_db_23ai.py <23ai.txt>` — CIS Oracle Database 23ai Benchmark v1.0.0,
  all 87 recommendations. Logic is written from each recommendation's audit SQL:
  parameter and profile checks read the queried value, privilege checks read the
  rows the query returns, audit checks read the enabled unified-audit options; the
  nine Manual recommendations are attestation booleans. The input contract is the
  Oracle Database 19c STIG module's, so one collector feeds both. Deprecated:
  CIS renamed the benchmark to 26ai (below).

- `gen_oracle_db_26ai.py <workbook.xlsx>` — CIS Oracle Database 26ai Benchmark v1.0.0,
  all 94 recommendations (81 Automated, 13 Manual), from the CIS workbook (needs
  openpyxl). Ids, titles, Automated/Manual status and the three Level 1 profiles
  (RDBMS; RDBMS on Linux / Windows host) are read from the workbook; the logic table
  carries over the 23ai logic plus the seven new recommendations. Automated checks
  fail closed with an "evidence missing" message per recommendation, and the
  generated tests give every recommendation a pass, a fail and (Automated) an
  evidence-missing case. Same input contract as 23ai.

- `gen_windows_server_2022.py <workbook.xlsx>` — CIS Microsoft Windows Server 2022 Benchmark v5.1.0, all
  408 recommendations, from the benchmark's Excel workbook (Combined Profiles sheet, read with the standard
  library). Registry checks are derived from each audit procedure, with the operator taken from the title;
  account policy, user rights and the Manual recommendations come from hand-written tables in the script.
  The evaluator and its unit tests are templates beside it (`windows_lib.rego.tmpl`,
  `windows_lib_test.rego.tmpl`); the per-recommendation tests are generated by
  `gen_windows_server_2022_tests.py`. Run `python3 scripts/coverage_stamp.py` afterwards.

- `gen_windows_server_2019.py <workbook.xlsx>`: CIS Microsoft Windows Server 2019 Benchmark v5.0.0,
  400 recommendations (393 in the L1/L2 x DC/MS profiles plus 7 opt-in Next Generation). Reuses the
  2022 generator's reader, check derivation and test builder; holds only the 2019 tables.

- `gen_suse_16.py <workbook.xlsx> [fields.json]`: CIS SUSE Linux Enterprise 16 Benchmark v1.0.0,
  336 recommendations across 22 section packages in the rhel_9 layout. Aborts on any count, status
  or logic mismatch with the workbook.

- `gen_ubuntu_26_04.py <workbook.xlsx> [fields.json]`: CIS Ubuntu Linux 26.04 LTS Benchmark v1.0.0,
  350 recommendations across 21 section packages, adapted from `gen_suse_16.py` (apt/dpkg, AppArmor,
  ufw, Ubuntu unit names). Each logic entry carries a title keyword; the run aborts on any count, status,
  logic or keyword mismatch with the workbook.

- `gen_sql_server_2025.py <workbook.xlsx> <repo root>`: CIS Microsoft SQL Server 2025 Benchmark v1.0.0,
  49 recommendations; Database Engine and AWS RDS profiles (`input.cis_profile.platform`).

- `gen_intune_defender_antivirus.py <workbook.xlsx> <repo root>`: CIS Microsoft Intune for Microsoft
  Defender Antivirus Benchmark v1.0.0, 55 recommendations keyed by CSP setting name.

- `gen_postgresql_17.py <workbook.xlsx> <benchmarks/cis/postgresql>`: CIS PostgreSQL 17 Benchmark v1.1.0,
  72 recommendations; per-control logic lives in `postgresql_17_spec.py`. Run `opa fmt -w` afterwards.

- `dump_workbook.py <workbook.xlsx> <out.json>`, then `gen_nginx.py <out.json> benchmarks/cis/nginx` or
  `gen_fortigate.py <out.json> benchmarks/cis/network_devices/fortinet`: CIS NGINX Benchmark v3.1.0
  (44 recommendations) and CIS FortiGate 7.4.x Benchmark v1.0.1 (64). Shared emitter: `cis_genlib.py`.

- `gen_rhel_9.py <workbook.xlsx> [fields.json]`: CIS Red Hat Enterprise Linux 9 Benchmark v3.0.0,
  352 recommendations, written into the existing rhel_9 package paths (14 section packages, roll-up
  `cis_rhel9`, bridge `cis_rhel9.main`, Level 2 view `cis_rhel9.l2`) on the shared Linux mapper
  contract. Aborts on any count, status, logic or title-keyword mismatch with the workbook.

The CIS OCI Foundations module (`benchmarks/cis/oci/`) is hand-written from the
public Prowler mapping of v3.1.0 and needs no generator.
