# Crosswalk CSVs

**Status:** shipping
**Kind:** export (Tier 1, data)
**Consumers:** GRC platforms that import control sets and mappings (Vanta, Drata, Secureframe, Hyperproof, ServiceNow IRM, Archer), spreadsheets

Four committed files under `dist/`, regenerated by `make crosswalk` and kept fresh by CI:

| file | rows | one row per |
|---|---|---|
| `controls.csv` | every inventory control | framework, control id, OSCAL id, statement, class, source, domains, Rego package, Rego file |
| `stig_to_800_53.csv` | 2,767 | DISA STIG rule → NIST SP 800-53 controls, with the platform prefix (`crosswalk/stig_800_53/data.json`) |
| `framework_to_800_53.csv` | authoritative map rows | framework control → 800-53 controls for every map in `crosswalk/framework_maps`, with its status; pending maps have no rows |
| `spine_800_53.csv` | 800-53 controls | the SCF-style pivot: baseline membership (Low / Moderate / High), STIG rules per platform, library controls whose id is that 800-53 control |

Nothing is invented. A cell is empty when no map says otherwise, and a map marked `pending` in
`framework_maps/data.json` contributes nothing until it is authoritative and cites its source.

`test/roundtrip.sh` proves every source row is present, none is invented, and the spine's STIG counts and
baseline nesting (every Moderate control is in High) hold.
